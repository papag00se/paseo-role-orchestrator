🧩 Anatomy of a role

🏷️
Name & delegation description
What a parent reads when it picks a child. It's never added to the role's own prompt.
🧠
Provider · model · reasoning · mode
The Paseo agent that actually runs whenever this role launches.
📜
System / role prompt
Standing instructions carried into every launch.
✅
Completion gate
An independent judge checks each finished turn against the workspace.
🤝
Delegation
Which roles it may launch, and how much of its session each child sees.
